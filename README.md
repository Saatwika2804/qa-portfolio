# Saatwika Selvakumar — QA Portfolio

## Publish using GitHub Pages

1. Sign in to GitHub and create a **public** repository named `qa-portfolio`.
2. Unzip this package on your computer.
3. In the new GitHub repository, select **Add file → Upload files**.
4. Upload `index.html` and `README.md`, then commit the changes.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/(root)`, then select **Save**.
8. Wait a few minutes. GitHub will display the published URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/qa-portfolio/`
9. Open the URL in a private/incognito window to confirm it works, then paste the actual URL into LinkedIn.

## Before publishing
- Replace the LinkedIn and GitHub placeholder text in `index.html` with your actual profile URLs.
- Check all dates and metrics for accuracy.
- The sample projects are clearly illustrative, not completed projects. Create supporting sample artifacts before presenting them as completed work.
- Never publish Amazon internal code, documents, customer data, or confidential information.

`index.html` is the website. `README.md` contains these instructions.
